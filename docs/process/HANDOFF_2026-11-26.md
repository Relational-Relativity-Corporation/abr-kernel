The session made a full circle: from the kernel's speed, through the foundation of the variables, to circuits, to text, and back to the same failure the 84th and 90th named, **a familiar method built in place of the operators**, this time a suffix match. The split, if kept, is a decomposition every relation carries, read by all three variables together. **The withdrawal is proposed, not yet recorded** (§6).

- **A test that cannot fail tells nothing:** several tests here hold by construction; each says so.
